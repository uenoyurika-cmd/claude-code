# 制作MTG資料 自動生成ツール

制作ミーティング資料の工数がかかる部分を自動化する Google Apps Script（GAS）Webアプリケーションです。

## 自動化する内容

- **制作目的・顧客課題の言語化** — メモ入力からAIがビジネス文書を生成
- **不要ページの取捨選択** — 内容が空のセクションのスライドを自動削除
- **デザインイメージの共有** — 要望に基づく参考サイトの自動提案
- **スケジュールのテキスト化** — ガントチャート画像からAIがスケジュールを読み取り
- **テンプレートへの自動流し込み** — Google Slidesテンプレートのプレースホルダーを自動置換

## 構成

```
gas/
├── appsscript.json      # GASマニフェスト（権限設定等）
├── Code.gs              # メインエントリポイント（doGet, processForm）
├── Config.gs            # 設定・スクリプトプロパティ管理
├── ClaudeService.gs     # Claude API連携（テキスト生成・画像解析）
├── SlideService.gs      # Google Slides テンプレート操作
├── Index.html           # Webアプリ メイン画面
├── Stylesheet.html      # CSS
└── JavaScript.html      # クライアントサイドJS
```

## セットアップ手順

### 1. GASプロジェクトの作成

1. [Google Apps Script](https://script.google.com/) にアクセス
2. 「新しいプロジェクト」を作成
3. `gas/` フォルダ内の各ファイルをGASエディタにコピー
   - `.gs` ファイル → スクリプトファイルとして作成
   - `.html` ファイル → HTMLファイルとして作成
   - `appsscript.json` → プロジェクトの設定 > 「appsscript.json」マニフェストファイルをエディタで表示 をONにして編集

### 2. Claude APIキーの設定

1. [Anthropic Console](https://console.anthropic.com/) でAPIキーを取得
2. GASエディタで「プロジェクトの設定」→「スクリプト プロパティ」
3. 以下のプロパティを追加:
   - `CLAUDE_API_KEY`: AnthropicのAPIキー

### 3. Google Slidesテンプレートの準備

テンプレートのスライド内に以下のプレースホルダーを配置してください:

| プレースホルダー | 置換内容 |
|---|---|
| `{{顧客名}}` | 顧客名 |
| `{{アカウントID}}` | アカウントID |
| `{{制作内容}}` | 制作内容 |
| `{{制作目的}}` | AIが生成した制作目的テキスト |
| `{{既存サイトの課題}}` | AIが生成した課題テキスト |
| `{{デザイン要望・提案}}` | AIが生成したデザイン提案テキスト |
| `{{デザイン参考}}` | AIが提案した参考サイト |
| `{{制作スケジュール}}` | 画像から抽出したスケジュールテキスト |
| `{{役務範囲}}` | チェックした役務範囲 |
| `{{日付}}` | 生成日（自動） |

テンプレートIDをスクリプトプロパティ `TEMPLATE_SLIDE_ID` に設定するか、`Config.gs` の `TEMPLATE_SLIDE_ID` を直接編集してください。

### 4. 出力先フォルダの設定（任意）

生成されたスライドの保存先フォルダを指定する場合:

- スクリプトプロパティに `OUTPUT_FOLDER_ID` を追加し、Google DriveのフォルダIDを設定

### 5. Webアプリとしてデプロイ

1. GASエディタで「デプロイ」→「新しいデプロイ」
2. 種類: 「ウェブアプリ」
3. 次のユーザーとして実行: 「自分」
4. アクセスできるユーザー: 組織内の全員（または必要な範囲）
5. 「デプロイ」をクリック
6. 生成されたURLにアクセスして使用開始

## 使い方

1. WebアプリのURLにアクセス
2. フォームに必要情報を入力
   - 顧客名（必須）、アカウントID、制作内容（必須）
   - 制作目的、既存サイトの課題、デザイン要望をメモ程度に入力
   - ガントチャートのスクリーンショットをドラッグ&ドロップ
   - 役務範囲をチェック
3. 「プレビュー生成」でAI生成結果を事前確認（任意）
4. 「スライド生成」で制作MTG資料を自動作成
5. 生成されたGoogle Slidesのリンクが表示される

## 使用技術

- **Google Apps Script** — Webアプリ / Google Slides API / Google Drive API
- **Claude API (Anthropic)** — テキスト生成 / 画像解析（Vision）
- **Google Slides** — テンプレートベースの資料生成
