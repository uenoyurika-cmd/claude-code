# Bookmark Manager+

Chromeのウィンドウの外でブックマークを直感的に管理できるChrome拡張機能です。
画面の上下左右に固定（ドッキング）して使えます。

## 機能

- **ウィンドウドッキング** - 画面の上・下・左・右・中央に固定配置（ワンクリックで切替）
- **ポップアップ表示** - 拡張機能アイコンからクイックアクセス
- **別ウィンドウモード** - Chrome外の独立ウィンドウでフル管理
- **ツリー表示 / グリッド表示** - 2つの表示モードを切り替え
- **ドラッグ＆ドロップ** - ブックマークをフォルダ間で直感的に移動
- **検索** - ブックマーク名・URLで即座に検索（Ctrl+F対応）
- **右クリックメニュー** - 編集・移動・削除をコンテキストメニューから操作
- **フォルダ管理** - サイドバーからフォルダ階層をナビゲーション
- **ワンクリック追加** - 現在のページをすぐにブックマーク

## デザイン

PANTONE 2021 Color of the Year をベースにした配色:
- **Illuminating** (#F5DF4D) - アクセントカラー、ボタン、アクティブ状態
- **Ultimate Gray** (#939597) - サブテキスト、アイコン、ボーダー

Fintech LP風のモダンなUIデザイン:
- 波型（Wave）セクション区切り
- 回路図パターンのオーバーレイ背景
- ピル型ボタン（Pill-shaped）
- Montserratフォント
- カード型UIと微細なシャドウ

## インストール方法

1. `chrome://extensions/` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `extension/` フォルダを選択

## ファイル構成

```
extension/
├── manifest.json    # Manifest V3 設定（bookmarks, storage, system.display）
├── background.js    # Service Worker（ドッキング計算・ウィンドウ管理）
├── popup.html       # ポップアップUI
├── popup.js         # ポップアップロジック
├── manager.html     # フル管理画面UI
├── manager.js       # フル管理画面ロジック
├── bookmarks.js     # 共通ブックマーク操作ユーティリティ
├── styles.css       # PANTONE 2021テーマスタイル
└── icons/           # 拡張機能アイコン
```

## ドッキング機能

ポップアップまたは管理画面のヘッダーにあるドッキングボタンで配置を選択:

| ボタン | 配置 | サイズ |
|--------|------|--------|
| 左 | 画面左端 | 幅30% × 高さ100% |
| 上 | 画面上端 | 幅100% × 高さ45% |
| 中央 | 画面中央 | 幅50% × 高さ65% |
| 下 | 画面下端 | 幅100% × 高さ45% |
| 右 | 画面右端 | 幅30% × 高さ100% |

選択した位置は自動的に保存され、次回起動時も同じ位置で開きます。
