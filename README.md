# Bookmark Manager Plus

Chromeのウィンドウの外でブックマークを直感的に管理できるChrome拡張機能です。

## 機能

- **ポップアップ表示** - 拡張機能アイコンからクイックアクセス
- **別ウィンドウモード** - Chrome外の独立ウィンドウでフル管理
- **ツリー表示 / グリッド表示** - 2つの表示モードを切り替え
- **ドラッグ＆ドロップ** - ブックマークをフォルダ間で直感的に移動
- **検索** - ブックマーク名・URLで即座に検索
- **右クリックメニュー** - 編集・移動・削除をコンテキストメニューから操作
- **フォルダ管理** - サイドバーからフォルダ階層をナビゲーション
- **ワンクリック追加** - 現在のページをすぐにブックマーク

## インストール方法

1. `chrome://extensions/` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. `extension/` フォルダを選択

## ファイル構成

```
extension/
├── manifest.json    # 拡張機能の設定ファイル (Manifest V3)
├── background.js    # Service Worker (別ウィンドウ起動)
├── popup.html       # ポップアップUI
├── popup.js         # ポップアップロジック
├── manager.html     # フル管理画面UI
├── manager.js       # フル管理画面ロジック
├── bookmarks.js     # 共通ブックマーク操作ユーティリティ
├── styles.css       # 全体スタイル
└── icons/           # 拡張機能アイコン
```

## 使い方

### ポップアップモード
拡張機能アイコンをクリックすると、コンパクトなブックマーク一覧が表示されます。フォルダの展開/折りたたみ、検索、ブックマークの追加ができます。

### 別ウィンドウモード
ポップアップ右上の「別ウィンドウで開く」ボタンをクリックすると、Chromeから独立したウィンドウで管理画面が開きます。サイドバーでフォルダをナビゲーションしたり、グリッド表示に切り替えたりできます。

### ドラッグ＆ドロップ
ブックマークをドラッグしてフォルダ上にドロップすると、そのフォルダに移動できます。
