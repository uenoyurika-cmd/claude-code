Meta 提案拡張機能

TD改善 & サイト改善見積もり for ferret One

ferret One のページを AI が分析し、TD 改善提案や
松竹梅の見積もりを自動生成する Chrome 拡張機能です。
自社単価表に基づいた正確な見積もり作成も可能です。

Background

こんな課題はありませんか？

  • ページが増えるたびに Title / Description の確認・修正が追いつかない
  • 手動でのチェックは 1ページずつ開いて確認する必要があり、膨大な時間がかかる
  • SEO の改善ポイントが 分からず、何を直せばいいか判断に迷う
  • 見積もり作成に時間がかかる ページ構成に応じた松竹梅の提案を手作業で作るのは非効率
  • 単価の計算ミスが不安 自社の複雑な料金表を手動で参照して見積もるため、ミスが起こりやすい

Benefits

この拡張機能で解決できること

1

2つのモードを搭載

TD改善モードと提案見積もりモードを切り替え可能。目的に応じて最適な機能を使い分けられます

2

AI が改善案を自動生成

OpenAI GPT-4o-mini がページを分析。TD改善案のほか、デザイン・UX・SEO等の包括的な改善提案を生成

3

松竹梅の見積もり自動作成

AIがサイト構成を分析し、プレミアム・スタンダード・ライトの3プランの見積もりを自動生成

4

自社単価表でカスタマイズ

約100項目の自社料金表をデフォルト搭載。単価の編集・項目追加・見積ルールの変更も自由自在

5

CSV 一括書き出し

TD提案も見積もりもExcel対応のCSVで出力。そのまま共有・レビュー・提案書作成に使えます

How to Use

使い方

1

OpenAI API Key を設定

拡張機能を開き、OpenAI の API Key を入力して「保存」をクリック。
API Key は Chrome のローカルストレージに保存され、外部には送信されません。

2

モードを選択

TD改善モード：全ページの Title / Description を AI が分析し、SEO 改善案を生成。
提案見積もりモード：サイト構成に基づき、松竹梅の3プランで見積もりを自動作成。

3

ページ一覧を取得

ferret One の「ページの一括設定」画面から自動取得、サイトマップ URL から取得、
または手動でページリストを入力できます。対象ページを選択してください。

4

単価設定を確認（見積もりモード）

自社の料金表がデフォルトで約100項目登録済み。
単価の変更、項目の追加・削除、ディレクション費率の調整なども可能です。

5

AI 提案を生成

TD改善モードでは各ページの改善案を、見積もりモードでは松竹梅3プランの見積もりを AI が自動生成。
見積もり結果は数量・単価を手動で調整でき、項目の追加・削除も可能です。

6

CSV で書き出し

TD改善案や見積もりの結果を CSV でダウンロード。
Excel で開いてチームレビューや提案書作成にそのまま活用できます。

活用シーン

定期運用

月次 SEO レビュー

毎月の SEO チェック業務で、全ページの TD を一括取得・AI分析。改善ポイントをCSVで共有し、チーム全体の SEO 品質を底上げ。

見積もり

松竹梅の提案見積もり作成

サイトマップやページリストから松竹梅3プランの見積もりを自動生成。自社単価表ベースで正確な金額を算出し、提案準備の工数を大幅削減。

提案資料

クライアントへの改善提案

TD改善案のCSVや松竹梅見積もりCSVをそのまま提案書に活用。デザイン・UX・SEO等の包括的な改善案も含め、説得力のある資料を作成。

新規制作

新規サイト制作の見積もり

作成予定のページリストを入力するだけで、ページ制作・デザイン・JSパーツ等の費用を自動算出。手動計算のミスを防ぎスピーディーに見積もりを提出。

単価管理

料金表の一元管理

自社の料金表を拡張機能内で管理。単価の変更やメニューの追加もすぐに反映され、常に最新の料金で見積もりを作成できます。

教育

SEO ナレッジの共有

AI の改善理由を参考にすることで、「なぜこう書くべきか」が学べる教材として活用。新人のSEOスキルアップに。

Installation

導入手順

共有ドライブからダウンロード

社内共有の Google Drive フォルダが開きます

  1. 上のリンクから社内共有ドライブを開き、フォルダごとダウンロードする
  2. ダウンロードした ZIP を展開（解凍）する
  3. Chrome で chrome://extensions を開く
  4. 右上の「デベロッパーモード」を ON にする
  5. 「パッケージ化されていない拡張機能を読み込む」をクリック
  6. 展開したフォルダ内の拡張機能フォルダを選択
  7. ツールバーに赤い M アイコンが表示されたらインストール完了

FAQ

よくある質問

OpenAI の API Key はどこで取得できますか？

OpenAI のアカウントで platform.openai.com にログインし、API Keys ページから発行できます。社内で共有キーが発行されている場合はそちらをご利用ください。

API の利用料金はどのくらいかかりますか？

GPT-4o-mini を使用しており、1ページあたり約 0.1〜0.3円 程度です。100ページで約10〜30円が目安です。

AI の処理中にページを移動しても大丈夫ですか？

はい。拡張機能は専用タブで動作するため、他のタブを閉じたり移動しても処理は継続します。ferret One のデータ取得後は ferret One タブを閉じても問題ありません。

ferret One 以外のサイトでも使えますか？

はい。「サイトマップから取得」機能で、任意のサイトの sitemap.xml URL を入力すれば利用できます。

データはどこかに送信されますか？

API Key はブラウザのローカルストレージに保存されます。ページのURL・Title・Description は AI 提案生成時に OpenAI API へ送信されます。それ以外の外部サーバーへの送信はありません。

松竹梅の見積もりとは何ですか？

松（プレミアム）・竹（スタンダード）・梅（ライト）の3段階の提案プランです。松はデザインリニューアルや競合分析を含む包括プラン、竹はバランスの良い中間プラン、梅はTD修正等の最小限プランです。クライアントの予算に応じた提案が可能です。

単価表はカスタマイズできますか？

はい。見積もりモードの「単価設定」パネルから、約100項目の単価を自由に編集できます。新しいメニュー項目の追加、不要な項目の削除、ディレクション費率や時間単価の変更も可能です。変更は「単価を保存」ボタンで保持され、「デフォルトに戻す」でいつでも初期値に戻せます。

見積もりの金額は手動で調整できますか？

はい。AI が生成した見積もりの数量・単価はすべて編集可能です。項目の追加・削除もでき、小計と合計はリアルタイムで再計算されます。最終的な調整後にCSV書き出しが可能です。
