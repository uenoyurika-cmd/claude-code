Meta 提案拡張機能

SEO Title / Description Optimizer for ferret One

ferret One の全ページの Title・Description を
AI が一括分析し、SEO 改善提案を自動生成する Chrome 拡張機能です。

Background

こんな課題はありませんか？

  • ページが増えるたびに Title / Description の確認・修正が追いつかない
  • 手動でのチェックは 1ページずつ開いて確認する必要があり、膨大な時間がかかる
  • SEO の改善ポイントが 分からず、何を直せばいいか判断に迷う
  • CSV で管理したいが データの収集と整形に手間がかかる

Benefits

この拡張機能で解決できること

1

ワンクリックで全ページ取得

ferret One の「ページの一括設定」画面からボタン1つで全ページのURL・タイトル・公開ステータスを取得

2

AI が改善案を自動生成

OpenAI GPT-4o-mini が各ページの Title / Description を分析し、SEO 改善案と理由を提案

3

CSV 一括書き出し

現在の値と提案値をExcel対応のCSVで出力。そのまま共有・レビュー・一括更新に使える

How to Use

使い方（5ステップ）

1

OpenAI API Key を設定

拡張機能を開き、OpenAI の API Key を入力して「保存」をクリック。
API Key は Chrome のローカルストレージに保存され、外部には送信されません。

2

ferret One からページ一覧を取得

別タブで ferret One の「ページの一括設定」画面を開いた状態で、拡張機能の「ferret One から取得」ボタンをクリック。
自動的にテーブルからURL・タイトル・公開ステータスを抽出します。
サイトマップ URL からの取得にも対応しています。

3

Title / Description を取得

対象ページにチェックを入れ「選択ページの TD 取得」ボタンをクリック。
各ページの HTML から title タグと meta description を自動取得します。

4

AI 提案を生成

「AI 提案を生成」ボタンで、全選択ページの改善案を一括生成。
1ページあたり約3〜5秒で処理が完了します。進捗バーで状況を確認できます。

5

CSV で書き出し

「CSV 書き出し」ボタンで、現在の Title / Description と AI 提案をまとめてダウンロード。
Excel で開いてチームレビューや一括更新作業にそのまま活用できます。

Use Cases

活用シーン

定期運用

月次 SEO レビュー

毎月の SEO チェック業務で、全ページの TD を一括取得・AI分析。改善ポイントをCSVで共有し、チーム全体の SEO 品質を底上げ。

新規制作

サイト公開前の TD 最適化

新しいサイトやページをリリースする前に、全ページの TD をまとめてチェック。公開前に SEO を担保。

提案資料

クライアントへの改善提案

CSV をもとに改善提案書を作成。「現在 → 提案」の比較表がそのまま資料になるため、提案準備の工数を大幅削減。

教育

SEO ナレッジの共有

AI の改善理由を参考にすることで、「なぜこう書くべきか」が学べる教材として活用。新人のSEOスキルアップに。

Installation

導入手順

  1. 社内リポジトリから chrome-extension フォルダをダウンロード
  2. Chrome で chrome://extensions を開く
  3. 右上の「デベロッパーモード」を ON にする
  4. 「パッケージ化されていない拡張機能を読み込む」をクリック
  5. ダウンロードした chrome-extension フォルダを選択
  6. ツールバーに赤い M アイコンが表示されたらインストール完了

FAQ

よくある質問

OpenAI の API Key はどこで取得できますか？

OpenAI のアカウントで platform.openai.com にログインし、API Keys ページから発行できます。社内で共有キーが発行されている場合はそちらをご利用ください。

API の利用料金はどのくらいかかりますか？

GPT-4o-mini を使用しており、1ページあたり約 0.1〜0.3円 程度です。100ページで約10〜30円が目安です。

AI の処理中にページを移動しても大丈夫ですか？

はい。拡張機能は専用タブで動作するため、他のタブを閉じたり移動しても処理は継続します。ferret One のデータ取得後は ferret One タブを閉じても問題ありません。

ferret One 以外のサイトでも使えますか？

はい。「サイトマップから取得」機能で、任意のサイトの sitemap.xml URL を入力すれば利用できます。

データはどこかに送信されますか？

API Key はブラウザのローカルストレージに保存されます。ページのURL・Title・Description は AI 提案生成時に OpenAI API へ送信されます。それ以外の外部サーバーへの送信はありません。
